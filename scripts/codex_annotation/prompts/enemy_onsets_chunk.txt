Blindly discover arena onsets in {PACKAGE_FILE} for {RUN_DIR}. This is the
primary chronological pass.

Do not read documentation, source, tests, Git state, labels, other runs,
caches, predictions, evaluation reports, own evidence, semantic JSON, or
worker transcripts. Do not print the package or manifest. Use a terse `jq`
command only to list its target range and primary artifact paths, then inspect
every listed primary image chronologically. Write only {OUTPUT_FILE}.

This stage decides only whether and when a genuinely new arena object/effect
begins. Do not decide side or card, and do not render identity sheets.

Maintain an active-object ledger across adjacent sheets. A moving unit,
attack, jump, projectile already in flight, bridge crossing, tower contact, or
body entering a crop is not a new onset. For each suspected onset:

1. Trace the same object backward through the preceding sheet(s).
2. Reject it if it was already present.
3. Find the earliest frame where the independent object/effect exists.
4. Trace it forward for at least five frames to distinguish a deployed object
   from a drag ghost, transient overlay, clock, glow, shadow, or impact debris.
5. Render two exact grid-free `arena` sheets: `onset-enemy-NNNNNN-before.jpg`
   covering at least n-6 through n-1, and
   `onset-enemy-NNNNNN-after.jpg` covering n through at least n+9. Clamp only
   at the prepared segment boundary.

Record a spell only from a new rolling object, directional projectile, or
coherent impact sequence. Record separate simultaneous objects separately.
Inspect the context halo, but emit only onsets whose earliest frame lies in
`owned_event_range`.
`focus_cell` is only the approximate visible center `[column,row]` of a new
unit/building at its first independent frame; use null for spells.
