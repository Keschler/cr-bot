WORKSPACE GUIDE

Watch your training

To save sampled matches from a new local V4 training run, prefix your usual training command with:

CR_SIM_VIEWER_DIR="$PWD/outputs/v4/RUN/viewer" \
CR_SIM_VIEWER_EVERY=5 \
<your training command>

Replace RUN with the run name. Capture is opt-in for newly started training processes. The first episode and every fifth episode start on lane 0 are sampled; a sample can be truncated or begin mid-match. Open an active recording to follow new frames as they arrive. Existing checkpoint files can be watched by launching an exhibition.
